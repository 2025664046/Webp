# 6장. 자바스크립트 언어

## 강의 목표
1. 자바스크립트 언어의 요소와 구조를 이해한다.
2. 자바스크립트 코드를 웹 페이지에 삽입하는 방법을 안다.
3. 자바스크립트로 브라우저에 출력하고 사용자 입력 받는 방법을 안다.
4. 자바스크립트에서 다루는 데이터 타입과 변수에 대해 이해한다.
5. 자바스크립트의 연산자의 종류를 알고 사용할 수 있다.
6. 자바스크립트의 조건문의 종류를 알고 사용할 수 있다.
7. 자바스크립트의 반복문의 종류를 알고 사용할 수 있다.
8. 자바스크립트 함수를 작성할 수 있다.
9. 사용자에게 제공되는 eval(), parseInt() 등 자바스크립트 함수를 활용할 수 있다.

## 1. 자바스크립트 언어 개요

- 1995년 넷스케이프에서 개발, Netscape Navigator 2.0 브라우저에 최초 탑재되며 웹 프로그래밍 개념을 창시함
- **특징**
  - HTML 문서에 조각 소스 코드로 내장되는 스크립트 언어
  - 인터프리터 방식으로 실행되어 별도의 컴파일이 필요 없음
  - C 언어의 구조를 차용해 비교적 단순하고 배우기 쉬움

### 웹 페이지에서 자바스크립트의 역할
- 사용자의 입력 및 계산: 마우스·키보드 입력은 오직 자바스크립트로만 처리 가능, 각종 계산 기능 수행
- 웹 페이지 내용 및 모양의 동적 제어: HTML 태그의 속성, 콘텐츠, CSS 프로퍼티 값을 동적으로 변경
- 브라우저 제어: 브라우저 창 크기·모양 제어, 새 창 열기/닫기, 다른 사이트 접속, 히스토리 제어
- 웹 서버와의 통신
- 웹 애플리케이션 작성: 캔버스 그래픽, 로컬/세션 스토리지 저장, 위치정보서비스 등

## 2. 자바스크립트 코드의 위치

작성 가능한 4가지 위치:
1. HTML 태그의 이벤트 리스너 속성에 작성
2. `<script></script>` 태그에 작성
3. 별도의 자바스크립트 파일(.js)에 작성
4. URL(href) 부분에 작성

### 예제 6-1: HTML 태그의 이벤트 리스너 속성에 자바스크립트 코드 작성
img 태그의 onmouseover/onmouseout 속성에 직접 코드를 써서, 마우스를 올리면 사과 이미지가 바나나로 바뀌고 내리면 다시 사과로 돌아오게 함.

### `<script>` 태그 작성 특징
- `<head></head>`나 `<body></body>` 내 어디든 작성 가능
- 한 웹 페이지 내에 여러 번 삽입 가능

### 예제 6-2: `<script>` 태그에 자바스크립트 코드 작성
head 안에 over()/out() 함수를 정의해두고, img 태그의 이벤트 속성에서 이 함수를 호출해 마우스 오버 시 이미지를 바꿈.

### 자바스크립트 파일로 분리하기
- `.js` 확장자 파일에 `<script>` 태그 없이 자바스크립트 코드만 저장
- 여러 웹 페이지에서 `<script src="파일이름.js">`로 불러와 중복 작성 없이 재사용

### 예제 6-3: 자바스크립트 파일 작성 및 불러오기
예제 6-2의 함수 코드를 lib.js 외부 파일로 분리하고, `<script src="lib.js">`로 불러와 동일하게 동작하도록 수정.

### 예제 6-4: 링크의 href에 자바스크립트 코드 작성
`<a href="javascript:alert(...)">` 형태로 링크를 클릭하면 alert 다이얼로그가 뜨도록 작성.

## 3. 자바스크립트로 HTML 콘텐츠 출력

- `document.write()`: HTML 콘텐츠를 웹 페이지에 직접 삽입해 바로 브라우저에 출력
- `document.writeln()`: 텍스트 뒤에 `'\n'`을 덧붙여 출력하지만 HTML에서는 줄바꿈 없이 빈칸 하나 정도의 효과만 있음

### 예제 6-5: document.write()로 웹 페이지에 HTML 콘텐츠 출력
document.write()를 여러 번 호출해 `<h3>`, 텍스트, `<mark>` 태그 등 다양한 HTML 콘텐츠를 순서대로 출력.

## 5. 식별자(Identifier)

자바스크립트 프로그램의 변수, 상수(리터럴), 함수의 이름.

### 식별자 작성 규칙
- 첫 번째 문자: 알파벳(A-Z, a-z), 언더스코어(`_`), `$` 문자만 사용 가능
- 두 번째 이후 문자: 알파벳, 언더스코어, 0-9, `$` 사용 가능
- 대소문자 구분됨 (`myHome`과 `myhome`은 다른 식별자)
- 예약어(`false`, `for`, `if`, `null` 등) 사용 불가

예시: `6variable`(✕, 숫자로 시작 불가), `student_ID`(○), `_code`(○이나 비권장), `if`(✕, 예약어), `%calc`(✕, `%` 사용 불가), `bar`와 `Bar`(○, 서로 다른 식별자)

## 6. 자바스크립트 문장

- 문장과 문장은 세미콜론(`;`)으로 구분하며, 한 줄에 한 문장만 있으면 세미콜론 생략 가능
- 한 줄에 여러 문장을 쓸 때는 각 문장 끝에 세미콜론이 반드시 필요함

### 주석문
```js
// 한 라인 주석. 라인의 끝까지 주석 처리
/*
   여러 라인 주석
*/
```

## 7. 데이터 타입

자바스크립트가 다루는 데이터 종류:
- **숫자 타입**: 정수, 실수 (예: 42, 3.14)
- **논리 타입**: 참/거짓 (true, false)
- **문자열 타입**: 예: `'좋은 세상'`, `"a"`, `"365"`, `"2+4"`
- **객체 레퍼런스 타입**: 객체를 가리킴. C 언어의 포인터와 유사
- **null**: 값이 없음을 표시하는 특수 키워드 (Null, NULL과는 다름)

→ 자바스크립트에는 별도의 문자(character) 타입이 없으며, 문자 하나도 문자열로 표현함.

## 8. 변수

변수는 자바스크립트 프로그램이 실행 중 데이터를 저장하는 공간이며, 변수 선언은 변수 이름을 정하고 저장 공간을 할당하는 것.

### 변수 선언 3가지 방법
- **var**: 자바스크립트 도입 시부터 있던 키워드, 지금도 사용
- **let**: var의 문제점을 해소하기 위해 2015년 ES6에서 추가
- **const**: 2015년 ES6에서 추가된 상수 선언 키워드(한 번 저장되면 값 변경 불가)

```js
var score;              // 변수 선언
var year, month, day;   // 여러 변수 동시 선언
var address = "서울시";   // 선언과 동시에 초기화

let score;
let year, month, day;
let address = "서울시";

age = 21;  // var나 let 없이 선언(이미 있으면 기존 변수에 저장)
```

- 자바스크립트는 변수 타입을 선언하지 않으며, 한 변수에 어떤 값(실수, 문자열 등)이든 저장 가능함

### 예제 6-6: 지역 변수와 전역 변수, 블록 변수
함수 f() 안에서 지역 변수 y와 if 블록 안의 블록 변수 b를 선언하고, 함수 밖에서 선언한 전역 변수 x·z와 함께 사용 범위(scope) 차이를 출력으로 확인.

### 변수의 사용 범위와 생명

| 구분 | 선언 방법 | 사용 범위 | 변수의 생명 |
|---|---|---|---|
| 전역 변수 | 함수 밖에서 선언, 혹은 var/let 없이 아무 곳에서나 선언 | 프로그램 전역 | 실행 시작 시 생성, 종료 시 소멸 |
| 지역 변수 | 함수 내에 let으로 선언 | 선언된 함수 내 | 함수 실행 시 생성, 종료 시 소멸 |
| 블록 변수 | let으로 if, while, for 등 블록 내에 선언 | 선언된 블록 내 | 블록 실행 시작 시 생성, 끝나면 소멸 |

### this로 전역변수 접근
지역 변수와 전역 변수의 이름이 같을 때, `this.전역변수`로 전역 변수에 접근할 수 있음. 단, let으로 선언된 전역 변수는 this로 접근할 수 없음.

### let의 특징
- var와 달리 동일한 변수를 재선언할 수 없어(재선언 시 오류) 변수 재선언으로 인한 코딩 오류를 줄여줌 → var보다 let 사용 권장
- 변수 사용 범위를 선언된 블록 내로 제한함

### 상수(const)
- `const MAX = 10;`처럼 변하지 않는 값을 가지는 이름을 선언
- 선언 후 값 수정 불가, 재선언 불가, 선언된 블록 범위에서만 사용 가능

## 9. 리터럴(Literal)

데이터 값 그 자체를 의미하며, 숫자·문자열·논리값 등 다양한 리터럴이 존재.

### 문자열 리터럴
- 이중 인용부호(`""`)와 단일 인용부호(`''`) 모두 사용 가능
- 문자열 안에 `"` 문자를 그대로 쓰려면 `\"`로 이스케이프

```js
let cite = "그녀는 \"누구세요\"라고 했습니다.";
```

### 예제 6-7: 리터럴
8진수(`015`), 16진수(`0x15`) 숫자 리터럴과 논리값, 단일/이중 인용부호 문자열, 이스케이프된 큰따옴표 문자열을 출력해 각 리터럴의 표현 방식을 확인.

## 10. 식과 연산자

### 산술 연산자
더하기(+), 빼기(-), 곱하기(*), 나누기(/), 나머지(%) 5가지. 나눗셈의 결과는 항상 실수로 계산됨(예: `32/10 = 3.2`).

### 예제 6-8: 산술 연산
변수 x를 이용해 사칙연산과 나머지 연산을 수행하고 total, div, mod 결과를 각각 출력.

### 증감 연산자 (++, --)
- 전위 연산자(`++a`): 먼저 증가시킨 후 그 값을 반환
- 후위 연산자(`a++`): 먼저 현재 값을 반환한 후 증가시킴

### 대입 연산자
오른쪽 식의 결과를 왼쪽 변수에 대입하며, `+=`, `-=`, `*=`, `%=` 등 복합 대입 연산자도 지원.

### 예제 6-9: 대입 연산
변수 x, y, z에 각각 `+=`, `*=`, `%=` 연산자를 적용해 변화되는 값을 출력.

### 비교 연산자
두 값을 비교해 true/false를 결과로 내는 연산(`==`, `!=`, `>`, `<`, `>=`, `<=`).

### 예제 6-10: 비교 연산
두 변수 x, y에 대해 모든 비교 연산자(==, !=, >=, >, <=, <)의 결과를 각각 출력.

### 논리 연산자
AND(`&&`), OR(`||`), NOT(`!`) 연산을 지원.

### 예제 6-11: 논리 연산
논리값 변수 x, y에 대해 AND/OR/NOT 연산과, 비교식들을 조합한 논리 연산 결과를 출력.

### 조건 연산자(삼항 연산자)
`condition ? expT : expF` 형태로, condition이 true면 expT, false면 expF의 값을 결과로 반환.

### 예제 6-12: 조건 연산
변수 a, b의 차이를 조건 연산자로 계산해(큰 값에서 작은 값을 빼는 방식) 출력.

### 비트 연산
숫자를 이진수(비트) 단위로 다루는 연산으로, 비트 논리 연산(AND, OR, XOR, NOT)과 비트 시프트 연산(좌측/우측 이동)으로 구분됨.

### 예제 6-13: 비트 연산
숫자를 8비트 이진수 문자열로 바꿔주는 digit8() 함수를 작성하고, &, |, ^, ~, <<, >>, >>> 연산 결과를 2진수와 10진수로 함께 출력.

### 문자열 연산자
- 문자열 연결: `+`, `+=` 연산자로 문자열과 문자열, 문자열과 숫자를 이어 붙임(숫자+문자열은 문자열로 변환되어 연결됨)
- 연산 순서에 유의: 숫자끼리 먼저 더해진 뒤 문자열과 연결되는지, 문자열이 먼저 연결된 뒤 숫자가 이어붙는지에 따라 결과가 달라짐
- 문자열 비교: `!=`, `==`, `>`, `<` 등 비교 연산자로 사전 순 비교 결과를 리턴

### 예제 6-14: 문자열 연산
숫자와 문자열을 다양한 순서로 `+` 연산해 연산 순서에 따른 결과 차이를 비교하고, 문자열 비교 연산자의 결과도 함께 출력.

## 11. 조건문

### if, if-else 문
```js
if(조건식) {
   // 조건식이 참인 경우 실행
}

if(조건식) {
   // 참인 경우
}
else {
   // 거짓인 경우
}

if(조건식1) {
   // 조건식1이 참인 경우
}
else if(조건식2) {
   // 조건식2가 참인 경우
}
else {
   // 모든 조건이 거짓인 경우
}
```

### 예제 6-15: if-else 사용
점수를 입력받아 90점 이상 A, 80점대 B, 70점대 C, 60점대 D, 그 미만 F로 학점을 매기는 if-else if 체인을 작성.

### switch 문
값에 따라 서로 다른 코드를 실행할 때 적합한 제어문. case의 '값'은 상수나 리터럴만 가능하며 변수나 식은 사용할 수 없음(단, `case 2+3:`처럼 상수들의 연산 결과는 가능).

### switch 문에서 break의 역할
break 문을 만날 때까지 아래 case로 실행이 계속 이어지며(fall-through), 이를 이용해 여러 case에 동일한 코드를 실행시키고 싶을 때는 의도적으로 break를 생략할 수 있음.

### 예제 6-16: switch 문 사용
prompt()로 입력받은 커피 종류에 따라 가격을 결정하는 switch 문을 작성하고, "espresso"와 "에스프레소"처럼 여러 case가 동일한 코드를 공유하도록(break 생략) 함.

## 12. 반복문

for 문, while 문, do-while 문 세 가지 형태를 지원.

### 예제 6-17: for 문으로 10px~35px 크기로 출력
for 문으로 size 변수를 10에서 35까지 5씩 증가시키며, 각 크기의 글자 크기를 가진 `<span>` 텍스트를 반복 출력.

### 예제 6-18: while 문으로 0~n까지의 합 구하기
prompt()로 입력받은 n을 parseInt()로 숫자로 변환한 후, while 문으로 0부터 n까지의 합을 누적 계산해 출력.

### 예제 6-19: do-while 문으로 0~n까지 합 구하기
예제 6-18과 동일한 합 계산 로직을 do-while 문으로 다시 구현.

### break 문과 continue 문
- **break**: 가장 안쪽 반복문 하나만 즉시 벗어남
- **continue**: 현재 반복의 나머지 코드 실행을 건너뛰고 다음 반복으로 넘어감

### 예제 6-20: break 문
무한 while 반복 안에서 1부터 계속 더하다가 합이 3000을 넘는 순간 break로 반복을 종료하고, 그때까지 더한 수와 합을 출력.

### 예제 6-21: continue 문
1부터 10까지 반복하면서 3으로 나눈 나머지가 1이 아닌 수는 continue로 건너뛰고, 나머지가 1인 수들만 출력 및 합산.

## 13. 함수

함수는 특정 목적을 가지고 작성된 코드 블록으로, 데이터를 전달받아 처리한 후 결과를 돌려줌.

### 함수의 구성과 호출
```js
function 함수이름(arg1, arg2, ..., argn) {
    // ...프로그램 코드...
    return 결과값; // 결과를 리턴하는 return 문
}

let n = adder(10, 20); // 함수 호출
```

### 예제 6-22: adder() 함수 작성 및 호출
두 수를 전달받아 합을 반환하는 adder(a, b) 함수를 작성하고, 큰 두 수를 전달해 호출한 결과를 출력.

## 14. 자바스크립트에서 제공하는 전역 함수

| 함수 | 설명 |
|---|---|
| `eval()` | 문자열로 된 수식을 계산해 결과를 리턴 (예: `eval("2*3+4*6")` → 30) |
| `parseInt()` | 문자열을 정수로 변환. `"0x32"`처럼 16진수 접두사가 있으면 16진수로 해석 |
| `isNaN()` | 값이 숫자가 아닌지(Not a Number) 판별해 true/false 리턴 |

### 예제 6-23: eval(), parseInt(), isNaN()
eval()로 수식 문자열을 계산하고, parseInt()로 10진수/16진수 문자열을 숫자로 변환하며, 숫자로 변환할 수 없는 문자열("hello")을 isNaN()으로 판별해 처리.

### 예제 6-24: 구구단 출력 함수 만들기
prompt()로 입력받은 단수(n)를 parseInt()로 변환한 뒤, isNaN() 및 범위 검사(1 ~ 9)로 잘못된 입력을 걸러내고, 유효하면 for 문으로 해당 단의 구구단(1 ~ 9배)을 출력하는 gugudan() 함수를 작성.
