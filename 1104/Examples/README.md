# 9장. 이벤트 기초 및 활용

## 강의 목표

1.  이벤트가 무엇이고 언제 발생하는지 이해한다.
2.  자바스크립트 코드로 이벤트 리스너를 작성할 수 있다.
3.  이벤트가 DOM 트리를 따라 흘러가는 경로를 이해한다.
4.  문서와 이미지의 로딩 완료 시 호출되는 onload 리스너를 작성할 수 있다.
5.  폼에 발생하는 이벤트 리스너를 다룰 수 있다.
6.  마우스 관련 이벤트를 다룰 수 있다.
7.  키 관련 이벤트를 다룰 수 있다.

------------------------------------------------------------------------

## 1. 이벤트 개요

-   **이벤트(Event)**: 마우스 클릭, 키보드 입력, 문서나 이미지의 로딩 등
    사용자의 행동이나 브라우저 상태 변화를 자바스크립트 코드에 알리는
    통지이다.
-   **이벤트 리스너(Event Listener)**: 발생한 이벤트에 대처하기 위해
    작성하는 자바스크립트 코드이다.
-   이벤트 리스너 이름은 이벤트 이름 앞에 `on`을 붙여 작성한다.
    -   예: `mousedown` 이벤트의 리스너는 `onmousedown`, `keydown`
        이벤트의 리스너는 `onkeydown`이다.
-   대표적인 이벤트에는 `load`, `click`, `dblclick`, `change`, `submit`,
    `reset`, `keydown`, `keyup`, `resize` 등이 있다.

------------------------------------------------------------------------

## 2. 이벤트 리스너 작성

이벤트 리스너는 다음과 같은 방법으로 작성할 수 있다.

### HTML 태그 내에 작성

-   HTML 태그의 이벤트 리스너 속성에 자바스크립트 코드를 직접 작성한다.
-   예: `onmouseover`, `onmouseout`을 이용해 마우스를 올리거나 내릴 때
    배경색을 변경한다.

### DOM 객체의 이벤트 리스너 프로퍼티에 작성

-   DOM 객체를 찾은 뒤 이벤트 리스너 프로퍼티에 함수를 등록한다.
-   `p.onmouseover = over;`와 같이 함수 이름을 등록하며,
    `p.onmouseover = over();`처럼 함수를 바로 호출하지 않는다.

### addEventListener() 메소드 활용

-   `addEventListener()` 메소드를 사용해 DOM 객체에 이벤트 리스너를
    등록한다.
-   하나의 객체에 여러 이벤트 리스너를 등록할 수 있다.

### 익명 함수로 이벤트 리스너 작성

-   함수 이름 없이 이벤트 리스너가 필요한 위치에 함수 코드를 직접
    작성한다.
-   코드가 짧거나 한 곳에서만 사용하는 경우 편리하다.

### 예제 9-1: HTML 태그 내에 이벤트 리스너 작성

HTML 태그에 `onmouseover`와 `onmouseout`을 작성하여 마우스를 올리면
배경색이 orchid로 바뀌고, 내리면 흰색으로 돌아오도록 한다.

### 예제 9-2: DOM 객체의 이벤트 리스너 프로퍼티에 리스너 등록

문서가 로드된 뒤 DOM 객체를 찾아 `onmouseover`와 `onmouseout` 프로퍼티에
함수를 등록하고, 마우스 움직임에 따라 배경색을 변경한다.

### 예제 9-3: addEventListener() 사용

`addEventListener()` 메소드로 마우스 이벤트 리스너를 등록하여 마우스를
올리거나 내릴 때 배경색이 변경되도록 한다.

### 예제 9-4: 익명 함수로 이벤트 리스너 작성

이벤트 리스너에 익명 함수를 직접 작성하여 마우스를 올리면 배경색이
바뀌고 내리면 원래 색으로 돌아오도록 한다.

## 3. 이벤트 객체

-   **이벤트 객체(Event Object)**: 발생한 이벤트에 관한 다양한 정보를
    담고 있는 객체이다.
-   마우스 이벤트 객체에는 마우스 좌표와 버튼 번호 등이 들어 있고, 키
    이벤트 객체에는 키 코드 등의 정보가 들어 있다.
-   이벤트 객체는 이벤트 리스너 함수의 첫 번째 매개변수로 전달받는다.
-   HTML 태그 안에서 이벤트 객체를 전달할 때는 `event`라는 이름을
    사용한다.
-   이벤트 객체의 `target` 프로퍼티는 이벤트를 발생시킨 DOM 객체를
    가리킨다.

### 예제 9-5: 이벤트 리스너에서 이벤트 객체 전달받기

버튼을 클릭하거나 문장 위에 마우스를 올렸을 때 이벤트 객체를 전달받고,
`type` 프로퍼티를 이용해 발생한 이벤트의 종류를 출력한다.

### 예제 9-6: 이벤트 객체의 프로퍼티 출력

버튼을 클릭하면 이벤트 객체의 `type`, `target`, `currentTarget`,
`defaultPrevented` 프로퍼티 값을 화면에 출력한다.

## 4. 이벤트의 디폴트 행동 취소

-   **디폴트 행동**: 특정 이벤트가 발생했을 때 HTML 태그가 기본적으로
    수행하는 행동이다.
    -   링크(`<a>`) 클릭: 웹 페이지 이동
    -   submit 버튼 클릭: 폼 데이터 전송
    -   체크박스 클릭: 체크박스 선택
-   이벤트 리스너에서 `false`를 리턴하거나 이벤트 객체의
    `preventDefault()` 메소드를 호출하면 디폴트 행동을 취소할 수 있다.
-   `cancelable` 프로퍼티가 `true`인 이벤트만 취소할 수 있다.

### 예제 9-7: 이벤트의 디폴트 행동 취소

링크를 클릭하면 이동 여부를 확인하고, 체크박스의 클릭 이벤트에서는
`preventDefault()`를 호출하여 체크 상태가 변경되지 않도록 한다.

------------------------------------------------------------------------

## 5. 이벤트 흐름

-   이벤트가 발생하면 `window` 객체에서 시작하여 DOM 트리를 따라 이벤트
    타겟에 도달한 뒤, 반대 방향으로 다시 `window` 객체까지 전달된다.
-   **캡쳐 단계(Capturing Phase)**: 이벤트가 `window`에서 이벤트 타겟
    방향으로 전달되는 과정이다.
-   **버블 단계(Bubbling Phase)**: 이벤트가 이벤트 타겟에서 `window`
    방향으로 전달되는 과정이다.
-   `addEventListener()`의 세 번째 매개변수를 `true`로 지정하면 캡쳐
    리스너, `false`로 지정하면 버블 리스너로 등록된다.
-   `stopPropagation()` 메소드를 호출하면 이벤트의 전달 흐름을 중단할 수
    있다.

### 예제 9-8: 이벤트 흐름

버튼을 클릭했을 때 body의 캡쳐 리스너, 버튼의 버블 리스너, body의 버블
리스너가 실행되는 순서를 확인한다.

## 6. 마우스 핸들링

-   `onclick`: HTML 태그를 클릭할 때 발생한다.
-   `ondblclick`: HTML 태그를 더블클릭할 때 발생한다.
-   `onmousedown`: 마우스 버튼을 누르는 순간 발생한다.
-   `onmouseup`: 눌렀던 마우스 버튼을 놓는 순간 발생한다.
-   `onmouseover`, `onmouseout`: 마우스가 태그 영역에 들어오거나 벗어날
    때 발생한다.
-   `onmouseenter`, `onmouseleave`: 마우스가 태그 영역에 들어오거나
    벗어날 때 발생하며 버블 단계가 없다.
-   `onwheel`: 마우스 휠을 굴리는 동안 발생한다.
-   `onmousemove`: 마우스를 움직일 때 발생하며, 이벤트 객체를 통해
    마우스 위치와 버튼 정보를 확인할 수 있다.
-   `oncontextmenu`: 마우스 오른쪽 버튼을 클릭했을 때 발생하며,
    `false`를 리턴하면 컨텍스트 메뉴의 기본 출력을 취소할 수 있다.

### 예제 9-9: onclick 리스너로 계산기 만들기

입력한 수식을 `eval()`로 계산하고, 계산 버튼을 클릭하면 계산 결과를 입력
창에 출력한다.

### 예제 9-10: 마우스 관련 이벤트 리스너

마우스를 누르거나 놓고, 태그 위에 올리거나 내리고, 휠을 움직일 때 글자
모양과 테두리 색·두께가 바뀌도록 한다.

### 예제 9-11: onmousemove와 마우스 위치 및 버튼

이미지 위에서 마우스를 움직일 때 이벤트 객체의 프로퍼티를 이용해 마우스
버튼 번호와 화면·브라우저·대상 객체 기준의 좌표를 출력한다.

### 예제 9-12: oncontextmenu로 소스 보기나 이미지 다운로드 금지

문서의 `oncontextmenu` 리스너에서 `false`를 리턴하여 마우스 오른쪽
클릭으로 나타나는 컨텍스트 메뉴를 막는다.

## 7. 문서와 이미지의 로딩 완료

### 문서 로딩 완료와 onload

-   `onload`는 웹 페이지의 로딩이 완료되었을 때 `window` 객체에서
    발생하는 이벤트이다.
-   `window.onload` 또는 `<body onload>`를 이용해 로딩 완료 후 실행할
    코드를 작성할 수 있다.

### 예제 9-13: onload에서 사이트 이전을 알리는 공고창 출력

웹 페이지의 로딩이 완료되면 `onload` 리스너가 실행되어 사이트 이전 안내
경고창을 출력한다.

### 이미지 로딩 완료와 onload

-   `<img>` 태그로 생성된 이미지 DOM 객체에 새 이미지 주소를 지정하면
    이미지 로딩이 시작된다.
-   이미지의 크기 등 로딩된 이미지 정보는 로딩이 완료된 뒤 `onload`
    리스너에서 확인해야 한다.

### 예제 9-14: onload로 이미지의 크기 알아내기

과일을 선택하면 해당 이미지가 로딩되고, 이미지의 `onload` 리스너에서
이미지의 폭과 높이를 출력한다.

### new Image()로 이미지 로딩과 출력

-   `new Image()`로 이미지 객체를 생성할 수 있으며, `src`에 파일 이름을
    지정하면 이미지를 미리 로딩할 수 있다.
-   로딩한 이미지 객체의 `src`를 `<img>` 객체에 지정하면 화면에 이미지를
    출력할 수 있다.

### 예제 9-15: new Image()로 이미지 로딩

여러 이미지 파일을 미리 로딩해 두고, 화면의 이미지를 클릭할 때마다 다음
이미지가 출력되도록 한다.

## 8. 포커스와 폼 관련 이벤트

### onblur와 onfocus

-   **포커스(Focus)**: 현재 키 입력을 받을 수 있는 상태이다.
-   `onfocus`: HTML 요소가 포커스를 얻을 때 발생한다.
-   `onblur`: HTML 요소가 포커스를 잃을 때 발생한다.
-   `focus()` 메소드를 호출하면 특정 요소에 포커스를 줄 수 있다.

### 예제 9-16: onfocus와 onblur, 입력 없이 다른 창으로 갈 수 없음

이름 입력 창에 포커스를 주고, 이름을 입력하지 않은 채 다른 요소로
이동하려 하면 다시 이름 입력 창에 포커스를 주도록 한다.

### 라디오버튼과 체크박스

-   라디오버튼은 `<input type="radio">`로 생성하며, 같은 `name`을 가진
    버튼 중 하나를 선택할 수 있다.
-   `document.getElementsByName()`으로 같은 이름을 가진 라디오버튼
    객체들을 찾을 수 있다.
-   체크박스는 `<input type="checkbox">`로 생성하며, 선택 여부는
    `checked` 프로퍼티로 확인한다.

### 예제 9-17: 선택된 라디오버튼 알아내기

같은 이름을 가진 라디오버튼들을 찾아 `checked` 프로퍼티를 확인하고,
선택된 버튼의 `value`를 출력한다.

### 예제 9-18: 체크박스로 선택한 물품 계산

물품 체크박스를 선택하거나 해제할 때마다 물품 가격을 합산하거나 빼서
전체 지불 금액을 자동으로 계산한다.

### select 객체와 onchange

-   `select` 객체는 `<select>` 태그로 만들어진 콤보박스이며, 각 옵션은
    `<option>` 태그로 표현한다.
-   `selectedIndex`로 현재 선택된 옵션의 인덱스를 확인할 수 있다.
-   선택된 옵션이 변경되면 `onchange` 리스너가 호출된다.

### 예제 9-19: select 객체에서 선택한 과일 출력

콤보박스에서 과일을 선택하면 `selectedIndex`와 `options`를 이용해 해당
과일의 이미지를 출력한다.

## 9. 키 이벤트

-   `onkeydown`: 키가 눌리는 순간 발생하며 모든 키에 대해 작동한다.
-   `onkeypress`: 문자 키와 Enter, Space, Esc 키를 누를 때 추가로
    발생한다.
-   `onkeyup`: 눌린 키를 놓는 순간 발생한다.
-   키 이벤트 객체의 `key`와 `code` 프로퍼티를 이용하면 입력된 키에 관한
    정보를 확인할 수 있다.

### 예제 9-20: 키 이벤트 리스너와 이벤트 객체의 프로퍼티

텍스트 입력 창에서 키를 누르면 이벤트 객체의 `key`와 `code` 값을 화면에
출력한다.

### 예제 9-21: 키 이벤트 응용 -- 상하좌우키로 셀 이동

3×3 표에서 방향키를 누르면 현재 선택된 셀의 배경색이 바뀌며, 표의 범위를
벗어나지 않도록 셀 사이를 이동한다.

------------------------------------------------------------------------

## 10. 폼 이벤트

-   `onreset`: reset 버튼을 클릭했을 때 발생하며, `false`를 리턴하면
    폼이 초기화되지 않는다.
-   `onsubmit`: submit 버튼을 클릭했을 때 발생하며, `false`를 리턴하면
    폼이 전송되지 않는다.
-   `onreset`과 `onsubmit` 이벤트 리스너는 `<form>` 태그에 작성한다.
