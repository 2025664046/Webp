# 3장. HTML5 문서 구조화와 웹 폼

## 1. 강의 목표
1. **HTML5 문서 구조화의 목적**과 **시맨틱 태그**에 대해 이해한다.
2. HTML5 시맨틱 태그로 **구조화된 웹 페이지**를 만들 수 있다.
3. **웹 폼(Web Form)의 목적**을 이해한다.
4. 웹 폼의 요소를 활용하여 사용자로부터 입력 받는 웹 페이지를 작성할 수 있다.

## 1. HTML5 문서 구조화

HTML5에서는 **시맨틱 태그**를 사용하여 문서의 구조와 의미를 나타낼 수
있다.

### 주요 시맨틱 태그

  태그          역할
  ------------- ----------------------------
  `<header>`    페이지나 영역의 제목, 소개
  `<nav>`       메뉴, 링크
  `<section>`   문서의 큰 영역
  `<article>`   독립적인 내용
  `<aside>`     본문과 관련된 보조 내용
  `<footer>`    페이지의 하단 정보

> 시맨틱 태그는 문서의 구조와 의미를 나타내며, 실제 위치나 디자인은
> CSS가 담당한다.

### 기본 구조 예제

``` html
<header>
    <h1>웹 프로그래밍</h1>
</header>

<nav>
    메뉴
</nav>

<section>
    <article>
        본문 내용
    </article>
</section>

<footer>
    하단 정보
</footer>
```

웹 페이지를 `header`, `nav`, `section`, `article`, `footer`로 나누어 구조화한다.

## 2. 기타 시맨틱 태그

  태그           역할
  -------------- ----------------------------
  `<figure>`     그림, 사진, 차트 등을 묶음
  `<details>`    자세한 내용을 접었다 펼침
  `<summary>`    details의 제목
  `<mark>`       내용을 강조
  `<time>`       시간이나 날짜 표시
  `<meter>`      측정값 표시
  `<progress>`   진행 상황 표시

### 예제

``` html
<details>
    <summary>질문</summary>
    답변 내용입니다.
</details>
```

제목을 클릭하면 숨겨진 내용을 펼쳐서 보여준다.

------------------------------------------------------------------------

## 3. HTML5에서 제거된 태그

HTML5에서는 일부 태그가 제거되었다.

예: `<big>`, `<center>`, `<font>`, `<frame>`, `<frameset>` 등

→ 디자인이나 화면 배치는 주로 **CSS**를 사용한다.

------------------------------------------------------------------------

# 4. 웹 폼

웹 폼은 사용자가 웹 페이지에서 **정보를 입력하고 전송**할 수 있도록 하는
기능이다.

예: - 로그인 - 회원가입 - 검색 - 예약 - 쇼핑

## `<form>` 태그

``` html
<form action="server.jsp" method="get">
    ...
</form>
```

-   `action` : 데이터를 보낼 서버 주소
-   `method` : 데이터를 보내는 방법

------------------------------------------------------------------------

## 5. 텍스트 입력

``` html
<input type="text">
<input type="password">
<textarea></textarea>
```

한 줄 글자, 비밀번호, 여러 줄의 글을 입력받는다.

------------------------------------------------------------------------

## 6. `<datalist>`

``` html
<input list="browsers">

<datalist id="browsers">
    <option value="Chrome">
    <option value="Edge">
</datalist>
```
 
선택할 수 있는 추천 목록을 보여준다.

------------------------------------------------------------------------

## 7. 버튼

``` html
<input type="button" value="버튼">
<input type="reset" value="초기화">
<input type="submit" value="전송">
```

일반 버튼, 입력 내용 초기화, 폼 데이터 전송 등에
사용한다.

------------------------------------------------------------------------

## 8. 체크박스

``` html
<input type="checkbox"> Java
<input type="checkbox"> HTML
```

여러 항목을 동시에 선택할 수 있다.

------------------------------------------------------------------------

## 9. 라디오 버튼

``` html
<input type="radio" name="gender"> 남자
<input type="radio" name="gender"> 여자
```

같은 `name`을 사용하면 여러 항목 중 하나만 선택할 수
있다.

------------------------------------------------------------------------

## 10. 콤보 박스

``` html
<select>
    <option>컴퓨터공학</option>
    <option>소프트웨어학과</option>
</select>
```

목록에서 하나를 선택할 수 있다.

`selected`를 사용하면 처음 선택된 항목을 지정할 수 있다.

------------------------------------------------------------------------

## 11. `<label>`

``` html
<label for="name">이름</label>
<input id="name" type="text">
```

입력 요소에 설명을 붙인다. `for`와 `id`를 연결할 수 있다.

------------------------------------------------------------------------

## 12. 색 입력

``` html
<input type="color" value="#00ff00">
```

색상을 선택할 수 있다.

색상은 `#rrggbb` 형식으로 표현한다.

------------------------------------------------------------------------

## 13. 날짜와 시간 입력

``` html
<input type="date">
<input type="time">
<input type="month">
<input type="week">
<input type="datetime-local">
```
날짜, 시간, 월, 주 등의 정보를 입력받는다.

------------------------------------------------------------------------

## 14. 숫자 입력

``` html
<input type="number" min="0" max="100" step="1">
```
숫자를 입력하고 최소값, 최대값, 증가 단위를 지정할 수 있다.

------------------------------------------------------------------------

## 15. 슬라이드 바

``` html
<input type="range" min="0" max="100">
```
슬라이더를 움직여 값을 선택한다.

------------------------------------------------------------------------

## 16. `placeholder`

``` html
<input type="text" placeholder="이름을 입력하세요">
```
입력하기 전에 입력 방법을 알려주는 안내 문구를 표시한다.

------------------------------------------------------------------------

## 17. 형식을 가진 입력

``` html
<input type="email">
<input type="url">
<input type="tel">
<input type="search">
```
이메일, URL, 전화번호, 검색어 등에 맞는 입력 형식을
사용한다.

------------------------------------------------------------------------

## 18. `<fieldset>`와 `<legend>`

``` html
<fieldset>
    <legend>회원 정보</legend>
    이름 <input type="text">
</fieldset>
```
관련된 폼 요소들을 하나의 그룹으로 묶고 제목을 붙인다.
