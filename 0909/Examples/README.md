# HTML5 기본 문서 만들기
---
## 강의 목표

1. 웹 페이지를 만드는 기초적인 HTML 태그들을 안다.
2. HTML5 기본 문서를 만들 수 있다.
3. 웹 페이지에 이미지, 표, 하이퍼링크를 삽입할 수 있다.
4. 인라인 프레임을 사용하여 웹 페이지에 다른 웹 페이지를 내장할 수 있다.
5. 오디오·비디오를 웹 페이지에 삽입할 수 있다.

---

## 1. HTML 페이지 기본

### 1.1 HTML5 페이지의 기본 구조

HTML5 문서는 문서 형식을 알리는 지시어로 시작하고, 그 아래에 문서 전체를 감싸는 요소와 두 개의 큰 영역이 놓인다.

| 구성 | 설명 |
|---|---|
| `<!DOCTYPE html>` | HTML5 문서임을 알리는 지시어. 문서 맨 앞에 위치 |
| `<html>` | 문서 전체를 감싸는 최상위 요소 |
| `<head>` | 문서 제목, 자바스크립트 코드, CSS 스타일 정의, 메타데이터를 담는 영역 |
| `<title>` | 브라우저 타이틀바(탭)에 표시되는 문서 제목 |
| `<body>` | 화면에 출력되는 본문 텍스트·이미지·테이블·동영상 등을 담는 영역 |

- 주석은 `<!--` 와 `-->` 사이에 작성하며, 브라우저 화면에 출력되지 않는다.
- 위 태그들은 HTML5 페이지의 **필수 태그**로 취급된다.

### 1.2 HTML 태그의 특징

**태그의 구성**

하나의 태그는 `태그 이름`과 0개 이상의 `속성(attribute)`으로 이루어지며, 속성은 `속성 이름 = "속성 값"` 형태로 작성한다.

**종료 태그 유무**

| 유형 | 설명 |
|---|---|
| 시작 태그 + 종료 태그 | 대부분의 태그. 콘텐츠를 감싸는 형태 |
| 시작 태그만 존재 | `<br>`, `<hr>`, `<img>`, `<meta>` 등 |

**대소문자 구분**

- 태그 이름과 속성 이름은 **대소문자를 구분하지 않는다.** 시작 태그를 대문자로, 종료 태그를 소문자로 써도 동작한다.
- 다만 가독성과 일관성을 위해 소문자로 통일해 쓰는 것이 권장된다.

**속성 값의 공백**

- 속성 값 앞뒤에 불필요한 공백 문자를 넣으면 **HTML5 표준에 어긋난다.** (예: 숫자 값 앞의 빈칸)

## 2. 기본 텍스트 태그

| 태그 | 이름 | 설명 |
|---|---|---|
| `<h1>` ~ `<h6>` | 헤딩(heading) | 문단 제목. `h1`이 가장 크고 중요하며 `h6`으로 갈수록 작아짐 |
| `<p>` | 단락(paragraph) | 본문을 여러 단락으로 나눔. 단락 사이에 여백이 생김 |
| `<hr>` | 수평선 | horizontal에서 딴 이름. 종료 태그를 사용하지 않음 |
| `<br>` | 줄바꿈 | 다음 줄로 넘어감. 연속 사용하면 여러 줄을 건너뜀 |
| `<pre>` | 미리 서식화된 텍스트 | 개발자가 입력한 공백과 줄바꿈을 **그대로** 출력 |

### 2.1 공백과 줄바꿈 처리 규칙

HTML의 기본 렌더링 규칙은 다음과 같다.

- 여러 개의 연속된 **빈 칸은 하나로** 취급된다.
- **엔터 키(줄바꿈)도 하나의 빈 칸**으로 처리되어, 여러 줄로 작성해도 한 줄에 이어 출력된다.
- 이 규칙을 피하고 입력한 포맷 그대로 보여주려면 `<pre>` 태그를 사용한다.

### 2.2 title 속성 — 툴팁

- 거의 모든 태그에 `title` 속성을 붙일 수 있다.
- 해당 요소 위에 마우스를 올리면(hover) 속성 값이 **툴팁**으로 출력된다.
- 요소에 대한 부가 설명을 제공할 때 사용한다.

### 2.3 텍스트 꾸미기 태그

| 태그 | 효과 |
|---|---|
| `<b>` | 진하게 (단순 시각적 강조) |
| `<strong>` | 중요한 내용 (의미적 강조 + 진하게) |
| `<em>` | 강조 (의미적 강조 + 이탤릭) |
| `<i>` | 이탤릭 (단순 시각적 기울임) |
| `<small>` | 한 단계 작은 글자 |
| `<del>` | 삭제된 내용 (취소선) |
| `<ins>` | 추가된 내용 (밑줄) |
| `<sup>` | 윗첨자 |
| `<sub>` | 아래첨자 |
| `<mark>` | 하이라이팅 (형광펜 효과) |

> `<b>`/`<i>`는 **모양**만 바꾸는 태그, `<strong>`/`<em>`은 **의미(중요도)**를 함께 전달하는 태그라는 점이 차이다. 태그는 중첩해서 함께 적용할 수도 있다.

## 3. 문자, 기호, 심볼 입력

### 3.1 HTML5의 문자 체계

- HTML5는 **유니코드 문자셋**을 사용하며, 코드 체계로 **UTF-8**을 사용한다.
- 한글을 포함한 페이지는 `<meta charset="utf-8">`로 인코딩을 지정해야 깨지지 않는다.

### 3.2 엔터티(entity)

다음과 같은 문자는 직접 입력할 수 없거나 입력해도 의도대로 출력되지 않는다.

- HTML의 **예약어**(태그 기호로 해석되는 문자)
- 키보드로 **입력이 어려운 기호**
- 수학·화폐 등의 **심볼**

이때 `&엔터티;` 또는 `&#코드값;` 형식으로 표현한다.

| 문자 | 엔터티 표현 | 코드 표현 |
|:---:|:---:|:---:|
| `"` | `&quot;` | `&#34;` |
| `'` | `&apos;` | `&#39;` |
| `<` | `&lt;` | `&#60;` |
| `>` | `&gt;` | `&#62;` |
| `&` | `&amp;` | `&#38;` |
| 빈칸 | `&nbsp;` | `&#160;` |
| `£` | `&pound;` | `&#163;` |
| `√` | `&radic;` | `&#8730;` |
| `∞` | `&infin;` | `&#8734;` |
| `↑` | `&uarr;` | `&#8593;` |
| `÷` | `&divide;` | `&#247;` |
| `∑` | `&sum;` | `&#8721;` |
| `©` | `&copy;` | `&#169;` |

> 연속된 빈칸은 하나로 합쳐지므로, 의도적으로 여러 칸을 띄우려면 `&nbsp;`를 필요한 개수만큼 사용한다.

## 4. 블록 태그와 인라인 태그

HTML 태그는 화면에 배치되는 방식에 따라 두 종류로 나뉜다.

### 4.1 블록(block) 태그

- 항상 **새 라인에서 시작**하여 출력된다.
- 양 옆에 다른 콘텐츠를 배치하지 않고 **한 라인을 독점**한다.
- 사례: `<p>`, `<h1>`, `<div>`, `<ul>`
- 가장 많이 사용되는 블록 태그는 **`<div>`** 이다.

### 4.2 인라인(inline) 태그

- 블록 속에 삽입되어 **블록의 일부**로 출력된다.
- 줄을 바꾸지 않고 콘텐츠 흐름 속에 자연스럽게 놓인다.
- 사례: `<strong>`, `<a>`, `<img>`, `<span>`
- 가장 많이 사용되는 인라인 태그는 **`<span>`** 이다.

### 4.3 활용

`<div>`와 `<span>`은 그 자체로는 특별한 모양이 없고, **CSS 스타일을 적용하기 위한 컨테이너** 역할을 한다. 블록 단위 영역 꾸미기에는 `<div>`, 문장 중 일부 단어만 꾸밀 때는 `<span>`을 사용한다.

## 5. 메타 데이터 삽입

### 5.1 메타 데이터란

**데이터를 설명하는 데이터**를 말한다.

| 데이터 종류 | 메타 데이터 예 |
|---|---|
| 사진 데이터 | 사진 찍은 장소, 시간 |
| 오디오 데이터 | 재생 시간, 채널 수 |
| 이미지 데이터 | 이미지의 폭, 높이, 컬러 해상도 |

### 5.2 메타 데이터 관련 태그

HTML 페이지에 대한 메타 데이터를 담기 위한 태그는 다음과 같다.

`<base>`, `<link>`, `<script>`, `<style>`, `<title>`, `<meta>`

- 이 태그들은 원칙적으로 **`<head>` 태그 안에 작성**한다.
- 단, `<script>`는 `<body>` 내에도 작성할 수 있다.

### 5.3 `<base>` 태그

- 웹 페이지들의 **기본 URL**과 페이지가 출력될 **윈도우**를 지정한다.
- 여러 링크가 같은 디렉터리를 가리킬 때, 기본 URL을 한 번만 선언하고 각 링크에는 파일 이름만 적을 수 있어 소스가 간결해진다.

### 5.4 `<link>` 태그

- **외부 자원을 연결**할 때 사용한다.
- 대표적으로 외부 CSS 파일(스타일 시트)을 불러오도록 지시한다.
- `type`(자원의 종류), `rel`(현재 문서와의 관계), `href`(자원의 위치) 속성을 함께 사용한다.

### 5.5 `<meta>` 태그

다양한 메타 데이터를 표현한다. 웹 페이지의 저작자, 문자 인코딩 방식, 내용 등을 나타낸다.

| 용도 | 지정 방식 |
|---|---|
| 저작자 표기 | `name="author"` 와 `content` |
| 페이지 내용 설명 | `name="description"` 와 `content` |
| 검색 키워드 | `name="keywords"` 와 `content` — 검색 엔진에 의해 검색되게 하기 위함 |
| 문자 코드 지정 | `charset` 속성 (예: `utf-8`) |

## 6. 이미지 삽입

`<img>` 태그의 `src` 속성에 이미지 파일의 주소를 지정한다.

### 6.1 지원 이미지 종류

BMP, GIF, PNG, JPG(JPEG), animated-GIF

### 6.2 주요 속성

| 속성 | 설명 |
|---|---|
| `src` | 이미지 파일의 URL. **필수 속성** |
| `alt` | 이미지가 없거나 손상되어 출력할 수 없을 때 대신 출력되는 문자열. **필수 속성** |
| `width` | 이미지가 출력되는 너비(픽셀). 생략하면 원본 이미지의 폭 |
| `height` | 이미지가 출력되는 높이(픽셀). 생략하면 원본 이미지의 높이 |

### 6.3 경로 지정

- `src`에는 **상대 경로명**과 **절대 URL(다른 사이트 주소)** 모두 사용할 수 있다.
- 상대 경로를 쓸 경우, 보통 HTML 파일이 있는 경로 아래에 `media` 같은 폴더를 만들고 그 안에 이미지를 두고 참조한다.
- 외부 사이트 이미지를 연결한 경우, 그 사이트의 주소가 바뀌면 이미지가 깨지고 `alt` 텍스트가 대신 출력된다.

## 7. 리스트 만들기

### 7.1 3가지 종류의 리스트

| 종류 | 태그 | 설명 |
|---|---|---|
| 순서 있는 리스트 (ordered list) | `<ol>` | 번호·문자 마커가 순서대로 붙음 |
| 순서 없는 리스트 (unordered list) | `<ul>` | 점(•) 등의 마커가 붙음 |
| 정의 리스트 (definition list) | `<dl>` | 용어와 설명의 쌍으로 구성 |

### 7.2 리스트 아이템

- 아이템은 `<li>` 태그로 작성하며, **종료 태그 `</li>`는 생략 가능**하다.
- 정의 리스트는 `<dt>`(용어)와 `<dd>`(용어 설명)로 구성한다.

### 7.3 `<ol>`의 속성

| 속성 | 설명 |
|---|---|
| `type` | 마커 종류 지정 |
| `start` | 마커의 시작 값 지정 |

**type 값**

| 값 | 마커 모양 |
|:---:|---|
| `1` | 1, 2, 3, … (디폴트) |
| `A` | A, B, C, … |
| `a` | a, b, c, … |
| `I` | I, II, III, … |
| `i` | i, ii, iii, … |

- `start` 속성은 **숫자에 대해서만 적용**된다.
- `<li>` 태그에도 `type` 속성을 줄 수 있으나 `<ol>` 태그에 대해서만 유효하다.
- `type`, `start` 속성 대신 **CSS3 스타일을 사용할 것을 권장**한다.

### 7.4 중첩 리스트

리스트 아이템 안에 다시 `<ul>`이나 `<ol>`을 넣어 계층적인 목록을 만들 수 있다. 안쪽 리스트는 자동으로 들여쓰기되고 마커 모양도 달라진다.

## 8. 표 만들기 — `<table>`

### 8.1 표 구성 태그

| 태그 | 역할 |
|---|---|
| `<table>` | 표 전체를 담는 컨테이너 |
| `<caption>` | 표 제목 |
| `<thead>` | 헤딩 셀 그룹 (헤더) |
| `<tbody>` | 데이터 셀 그룹 (바디) |
| `<tfoot>` | 바닥 셀 그룹 (바닥) |
| `<tr>` | 행(row). 여러 `<td>`, `<th>`를 포함 |
| `<th>` | 열 제목(헤딩) 셀 |
| `<td>` | 데이터 셀 |

### 8.2 구조 규칙

- **`<caption>`은 `<table>` 내에 반드시 첫 번째로 삽입**해야 한다.
- 표는 여러 **행(`<tr>`)** 으로 구성되고, 한 행은 여러 **셀(`<th>`, `<td>`)** 로 구성된다.
- `<thead>`, `<tbody>`, `<tfoot>`은 각각 여러 개의 `<tr>`을 포함할 수 있다.
- 소스 상 `<tfoot>`을 `<tbody>`보다 먼저 써도, 브라우저는 바닥 영역을 표의 맨 아래에 출력한다.

### 8.3 테두리

- `border` 속성으로 테두리 굵기를 지정할 수 있다(예: 1픽셀).
- 값을 주지 않으면 디폴트 굵기(0)로 테두리가 제거된다.
- 테두리 굵기·색 등의 꾸밈은 **CSS3로 나타내는 것이 바람직**하다.

### 8.4 셀의 내용

셀(`<td>`) 안에는 텍스트뿐 아니라 이미지, 링크 등 다양한 요소를 넣을 수 있다.

## 9. 하이퍼링크 만들기 — `<a>`

### 9.1 하이퍼링크란

- 다른 HTML 페이지로의 **연결 고리**이다.
- **같은 웹 사이트**의 다른 HTML 페이지, **다른 웹 사이트**의 HTML 페이지 모두 연결 가능하다.
- 하이퍼링크는 **텍스트나 이미지**로 작성할 수 있다.
- **항해(navigation)**: 하이퍼링크를 따라 다른 웹 페이지를 방문하는 것.

### 9.2 `<a>` 태그의 속성

| 속성 | 설명 |
|---|---|
| `href` | 이동할 HTML 페이지의 URL 혹은 HTML 페이지 내 앵커 이름 |
| `target` | 링크에 연결된 HTML 페이지가 출력될 윈도우 이름 지정 |
| `id` | 페이지 내 앵커(특정 위치) 생성 |
| `download` | 링크 클릭 시 페이지 이동 대신 파일을 다운로드 |

`href`에 지정 가능한 형태는 `URL`, `URL#앵커이름`, `#앵커이름` 이다.

### 9.3 하이퍼링크 텍스트의 색

| 상태 | 기본 색 |
|---|---|
| 링크 텍스트(standard link) | 밑줄과 함께 **blue** |
| 방문 후 링크(visited link) | **purple** |
| 마우스로 누르고 있는 동안(active link) | **red** |

- 링크 색은 **CSS3를 이용하여 변경**할 수 있다.

### 9.4 앵커(anchor)

- 앵커란 **HTML 페이지 내의 특정 위치**를 말한다.
- 태그에 `id` 속성을 주어 앵커를 만들고, `href="#앵커이름"` 형태의 링크로 그 위치로 이동한다.
- `<a>` 태그뿐 아니라 `<h3>` 같은 일반 태그에도 `id`를 주어 앵커로 삼을 수 있다.
- 목차에서 본문의 각 절로 점프하는 기능을 만들 때 주로 사용한다.

### 9.5 파일 다운로드 링크

- `<a>` 태그에 `download` 속성을 추가하면, 링크 클릭 시 해당 파일이 **다운로드**된다.
- 이미지, PDF, MP3, HTML, 한글 파일 등 종류를 가리지 않고 적용할 수 있다.

## 10. 인라인 프레임 — `<iframe>`

### 10.1 개념

- `<iframe>`은 **HTML 페이지 내에 또 다른 HTML 페이지를 삽입**하는 태그이다.
- 같은 사이트의 페이지는 물론, 외부 사이트의 페이지도 내장할 수 있다.

### 10.2 주요 속성

| 속성 | 설명 |
|---|---|
| `src` | 출력할 웹 페이지의 URL 주소 |
| `srcdoc` | 직접 HTML 태그로 작성된 텍스트로서 출력될 내용 |
| `name` | 프레임 윈도우의 이름. 다른 웹 페이지에서 `target` 속성 값으로 사용 |
| `width` | 프레임의 폭(픽셀). 디폴트 300 |
| `height` | 프레임의 높이(픽셀). 디폴트 150 |

- 시작 태그와 종료 태그 사이에 적은 텍스트는 `<iframe>`을 지원하지 않는 브라우저에서 **대신 출력**된다.
- **`srcdoc` 속성이 있으면 `src` 속성은 무시된다.**

### 10.3 브라우저 윈도우와 인라인 프레임의 계층 관계

- 브라우저 윈도우와 프레임 윈도우는 **부모-자식 관계**를 이룬다.
- 프레임 안에 또 프레임을 넣으면 계층이 더 깊어진다.

| 용어 | 의미 |
|---|---|
| parent 윈도우 | 부모 윈도우 |
| child 윈도우 | 자식 윈도우 |
| top 윈도우 | 최상위 브라우저 윈도우 |

예를 들어 브라우저 윈도우가 `left`·`right` 두 프레임을 가지고, `right` 프레임이 다시 `upper`·`lower` 프레임을 가지는 경우:

- `left`, `right`의 parent 윈도우 → 브라우저 윈도우
- `upper`, `lower`의 parent 윈도우 → `right` 윈도우
- `left`, `right`, `upper`, `lower` 모두의 top 윈도우 → 브라우저 윈도우

### 10.4 `target` 속성으로 출력할 윈도우 지정

`<base>`, `<a>`, `<area>`, `<form>` 태그에서 HTML 페이지를 출력할 윈도우를 지정한다.

| 값 | 의미 |
|---|---|
| `_blank` | 새로운 브라우저 윈도우(탭) 생성 |
| `_self` | 현재 윈도우 (탭 혹은 프레임 윈도우) |
| `_parent` | 부모 윈도우 |
| `_top` | 최상위 브라우저 윈도우. 모든 프레임 윈도우가 제거됨 |
| 윈도우 이름 | `name`으로 지정한 대상 윈도우 |

> 왼쪽 프레임에 메뉴(사이트 목록)를 두고, 클릭 결과를 오른쪽 프레임에 출력하는 구성이 `target`의 대표적 활용이다.

## 11. 미디어 삽입

### 11.1 HTML5의 미디어 표준화

- HTML5는 웹 페이지에 미디어를 삽입하는 방법을 표준화하여 **`<audio>`, `<video>` 태그**를 제공한다.
- 이들은 **플러그인이 필요 없으며**, HTML5 표준 브라우저는 플러그인 없이 오디오·비디오를 재생한다.
- 플래시 등 **비표준 미디어**를 재생할 때는 `<embed>`, `<object>` 태그를 사용한다.

### 11.2 `<video>` 태그

| 속성 | 설명 |
|---|---|
| `src` | 비디오 파일의 URL |
| `width`, `height` | 비디오가 재생될 브라우저 공간의 폭과 높이. 생략되면 비디오 원본 크기 |
| `controls` | 설정되면 재생, 재생 시간, 중단, 음소거 등 **제어 버튼 출력** |
| `autoplay` | 설정되면 비디오 로딩 즉시 재생 |
| `loop` | 설정되면 반복 재생 |
| `muted` | 오디오를 끌 때 사용 |

### 11.3 `<audio>` 태그

| 속성 | 설명 |
|---|---|
| `src` | 오디오 파일의 URL |
| `controls` | 제어 버튼 출력 |
| `autoplay` | 로딩 즉시 재생 |
| `loop` | 반복 재생 |

### 11.4 `<source>` 태그로 소스 별도 지정

- `src` 속성 대신 `<source>` 태그로 미디어 소스를 지정할 수 있다.
- `type` 속성에 마임 타입을 적어준다.
- **여러 개의 `<source>`를 나열하면 브라우저가 재생 가능한 것을 위에서부터 선택**한다. (예: MP3를 재생할 수 없으면 OGG 선택)

### 11.5 마임 타입(MIME Type)

| 미디어 | 마임 타입 | 설명 |
|---|---|---|
| MP4 | `video/mp4` | H.264 비디오와 AAC 오디오 코덱으로 인코딩된 MPEG 4 파일 |
| WebM | `video/webm` | VP8 비디오와 Vorbis 오디오 코덱으로 인코딩된 WebM 파일 |
| Ogg | `video/ogg` | Theora 비디오와 Vorbis 오디오 코덱으로 인코딩된 Ogg 파일 |
